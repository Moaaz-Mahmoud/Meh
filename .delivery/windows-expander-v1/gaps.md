## 2. Conflicts / constraints
- No Windows Rust target in the dev workspace (`E0463`), so all Win32 code is proven only on `windows-latest`. Mitigation: keep matcher/config/expansion pure and tested on Linux; put Win32 in thin modules. `windows-sys` type-checks on Linux (probe passed), so avoid gating those modules by `cfg(windows)` where possible. `tray-icon`, `winresource` and the installer cannot be checked locally.
- D-03 (CI only on deliberate triggers, no push/PR trigger) means few chances to catch Windows compile errors, and a failed tag run leaves a bad tag. Mitigation: `workflow_dispatch` build-only mode (no release) run as soon as the Win32 layer lands; tag only after it is green and the human has smoke-tested the portable exe.
- CI proves compile + packaging only; hook, injection, dead keys and installer behavior need a manual smoke test on a real Windows machine (human). Not verifiable in this session.
- `serde_yaml` is deprecated and `serde_yml` is unsound (RUSTSEC-2025-0068); the crate choice must be isolated so it can be swapped.
- Espanso parity is partial: buffer-reset, `word:true` separator rule and case sensitivity are unverified, so v1 defines its own and says so in the README. Raw Input (espanso legacy) vs LL hook (ours) is a deliberate divergence; hook gives the injected flag but can be silently removed.
- `windows-latest` image is a moving target (VS2026 migration); Inno Setup is on both. Consider pinning the runner label.

## 3. Proposed v1 cut (fits 1 hour)
Two crates/modules: a pure `core` (config parse via `serde_norway`, rolling buffer, plain + `word:true` matching, `{{date}}` with format/offset, `$|$` split, escaping) with Linux unit tests, and a thin Windows layer: LL keyboard + mouse hooks feeding a channel, worker thread doing matching and `SendInput` (tagged `dwExtraInfo`, VK_BACK erase, Unicode inject, VK_RETURN newlines, Left-arrow cursor), tray via `tray-icon` (Enable/Disable, Reload, Open config, Quit), `CreateMutexW` single instance, file log. Packaging: `winresource` icon/version, Inno Setup per-user installer with optional autostart, `Compress-Archive` zip, one workflow triggered by `v*` tag and `workflow_dispatch` (build-only vs release). Clipboard variable only if time remains.

## 4. Deferred
